# Wildlife ROS 2 — v0.2

ROS 2 Jazzy + Ubuntu 24.04 academic multi-UAV/UGV simulation baseline.

## Demo flow

`UGV -> typed deployment -> UAV search -> dummy/OpenCV detection -> target tracking/fusion -> assignment -> standoff -> operator RETURN/HOLD -> return/docking`

The project is intentionally scoped to non-contact search, detection, tracking, standoff and return/docking behaviors.

## Build

```bash
source /opt/ros/jazzy/setup.bash
cd ~/wildlife_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

## Logic-only demo

```bash
ros2 launch wildlife_bringup subject1_demo.launch.py
```

## Gazebo demo

Install the Gazebo/bridge packages described in `docs/DEPENDENCIES.md`, then:

```bash
ros2 launch wildlife_bringup subject2_demo.launch.py
```

The Gazebo UAVs in v0.2 are visual proxy vehicles. PX4 SITL is deliberately deferred to v0.3.

## Operator decision

```bash
ros2 service call /operator/decision wildlife_interfaces/srv/OperatorDecision \
"{target_id: target_001, assigned_drone_id: uav01, decision: 0, operator_notes: 'return'}"
```

`0 = RETURN`, `1 = CONTINUE_HOLD`.

See `ARCHITECTURE.md`, `docs/V0_2_SCOPE.md`, and `docs/DEPENDENCIES.md`.

# v0.2 architecture

```text
wildlife_interfaces
        |
        +--> wildlife_vehicles ---- UGV / deployment / UAV / docking
        |
        +--> wildlife_perception -- dummy detector / optional OpenCV detector
        |             |
        |             v
        +--> wildlife_targets ---- mux / tracker / target manager
        |             |
        |             v
        +--> wildlife_swarm ------- assignment / deconfliction
        |             |
        |             v
        +--> wildlife_mission ---- mission FSM / standoff / operator service
        |
        +--> wildlife_core -------- visualization / math / state
        |
        +--> wildlife_simulation -- Gazebo assets / ros_gz bridge / adapters
        |
        +--> wildlife_bringup ----- Subject 1 and Subject 2 launch profiles
```

### External integration boundary

`Gazebo -> ros_gz_bridge -> ROS 2`

`PX4 SITL -> ROS 2/PX4 bridge (v0.3)`

`QGroundControl -> PX4 telemetry/vehicle control (v0.3)`

`Camera -> OpenCV/YOLO -> Detection`.

The rest of the project consumes `Detection` and does not depend on the detector implementation.

# Wildlife ROS 2 v0.2 scope

v0.2 implements the council changes from v0.1.1 and adds the first Gazebo layer.

### Included
1. `wildlife_tracking` is merged into `wildlife_targets`.
2. Typed deployment/operator/mission interfaces are used instead of String command parsing.
3. YAML parameter files are installed with the packages.
4. RViz visualization and dedicated Subject 1 / Subject 2 demo launches are retained.
5. Gazebo world + UGV + 8 UAV visual proxy models are included.
6. `ros_gz_sim` spawning and a minimal `ros_gz_bridge` configuration are included.
7. OpenCV camera detection plumbing is available as an optional backend.
8. The existing dummy detector remains available for deterministic demonstrations.
9. PX4 SITL/QGroundControl/micro-ROS/YOLO are documented as later integration layers.

### Not claimed as complete in v0.2
- PX4 flight dynamics or PX4 offboard control.
- QGroundControl mission control integration.
- YOLO inference.
- Nav2 autonomous UGV navigation.
- Full Gazebo-to-ROS synchronization for every UAV state.

These are intentionally staged for v0.3 rather than making v0.2 depend on a large external stack.

# v0.2 dependency plan

## Integrated now
- ROS 2 Jazzy
- Gazebo Harmonic / `gz sim` (visual simulation layer)
- `ros_gz_sim` + `ros_gz_bridge` (Gazebo spawn/bridge)
- OpenCV + `cv_bridge` (optional camera detector executable)

## Deliberately deferred
- **PX4 SITL:** not hard-wired into v0.2. The UAV model is a simple Gazebo visual proxy so the ROS mission logic remains buildable without a PX4 checkout. v0.3 will replace the proxy with PX4 SITL vehicle instances and `px4_msgs`/offboard integration.
- **QGroundControl:** desktop ground-control application; no ROS package is required. Use it alongside PX4 SITL once PX4 is integrated.
- **micro-ROS Agent:** deferred until a microcontroller/embedded node is introduced.
- **Ultralytics YOLO:** deferred until the camera/image pipeline is validated. The intended contract is to keep publishing the existing `wildlife_interfaces/Detection` message, so the detector can be swapped without changing tracking/mission code.

## Ubuntu 24.04 setup

Core ROS/Gazebo packages should be installed through the ROS 2 Jazzy apt repository. Python OpenCV is optional for the camera detector:

```bash
sudo apt install ros-jazzy-ros-gz-sim ros-jazzy-ros-gz-bridge ros-jazzy-cv-bridge python3-opencv
```

If you do not want camera processing yet, you can omit OpenCV/cv_bridge and run the `detector_sim` backend.

## PX4 integration boundary

The project deliberately uses a stable ROS-side interface:

`camera -> Detection -> tracking/fusion -> Target -> assignment -> standoff -> operator decision`

PX4 should own vehicle flight/autopilot behavior. The mission layer should send high-level flight intent, not duplicate PX4's inner-loop controller.

from launch.conditions import IfCondition

from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare

def generate_launch_description():
    sim=LaunchConfiguration('use_gazebo')
    world=PathJoinSubstitution([FindPackageShare('wildlife_simulation'),'worlds','wildlife_field.sdf'])
    bridge=PathJoinSubstitution([FindPackageShare('wildlife_simulation'),'config','bridge.yaml'])
    ugv=PathJoinSubstitution([FindPackageShare('wildlife_simulation'),'models','ugv','model.sdf'])
    uav=PathJoinSubstitution([FindPackageShare('wildlife_simulation'),'models','uav','model.sdf'])
    actions=[DeclareLaunchArgument('use_gazebo',default_value='true')]
    actions.append(ExecuteProcess(cmd=['gz','sim','-r',world],output='screen',condition=IfCondition(sim)))
    actions.append(Node(package='wildlife_simulation',executable='ugv_gazebo_adapter',name='ugv_gazebo_adapter',output='screen'))
    actions.append(TimerAction(period=2.0,actions=[Node(package='ros_gz_bridge',executable='parameter_bridge',arguments=['--ros-args','-p',f'config_file:={bridge}'],output='screen')]))
    actions.append(TimerAction(period=3.0,actions=[Node(package='ros_gz_sim',executable='create',arguments=['-name','ugv','-file',ugv,'-x','0','-y','0','-z','0.25'],output='screen')]))
    for i in range(1,9):
        x=((i-1)%4)*3.0+2.0; y=((i-1)//4)*4.0-2.0
        actions.append(TimerAction(period=4.0+i*0.15,actions=[Node(package='ros_gz_sim',executable='create',arguments=['-name',f'uav{i:02d}','-file',uav,'-x',str(x),'-y',str(y),'-z','0.25'],output='screen')]))
    return LaunchDescription(actions)

import math, time
import rclpy
from rclpy.node import Node
from wildlife_interfaces.msg import DroneCommand, DroneState, Target, OperatorAlert

class UAVNode(Node):
    def __init__(self):
        super().__init__('uav_manager')
        for name,default in {
            'drone_id':'uav01','slot_id':1,'is_upper_position':True,'search_altitude':10.0,'standoff_distance':12.0,
            'search_speed':1.2,'loiter_duration':20.0,'search_timeout':90.0,'battery_drain_per_second':0.15,
            'lane_spacing':5.0,'search_half_width':30.0,'standoff_altitude_offset':3.0,'motion_tolerance':0.5,'home_x':0.0,'home_y':0.0}.items(): self.declare_parameter(name,default)
        g=lambda k:self.get_parameter(k).value
        self.id=str(g('drone_id')); self.slot_id=int(g('slot_id')); self.is_upper=bool(g('is_upper_position')); self.alt=float(g('search_altitude')); self.standoff=float(g('standoff_distance')); self.speed=float(g('search_speed')); self.loiter=float(g('loiter_duration')); self.timeout=float(g('search_timeout')); self.drain=float(g('battery_drain_per_second')); self.lane=float(g('lane_spacing')); self.half_width=float(g('search_half_width')); self.alt_offset=float(g('standoff_altitude_offset')); self.tol=float(g('motion_tolerance')); self.home_x=float(g('home_x')); self.home_y=float(g('home_y'))
        self.state=DroneState.STORED; self.x=self.y=self.z=0.; self.battery=100.; self.target=None; self.search_start=None; self.loiter_start=None; self.last=time.monotonic(); self.lane_dir=1.; self.hold_position=False; self.alerted_target=None
        self.state_pub=self.create_publisher(DroneState,'/drones/state',20); self.alert_pub=self.create_publisher(OperatorAlert,'/operator/alerts',20)
        self.create_subscription(DroneCommand,'/deployment/commands',self.command_cb,20); self.create_subscription(DroneCommand,'/mission/drone_commands',self.command_cb,20); self.create_subscription(Target,'/targets/assigned',self.target_cb,20); self.create_subscription(Target,'/targets/operator_decision',self.decision_cb,20)
        self.create_timer(0.1,self.tick)
    def command_cb(self,m):
        if m.drone_id!=self.id: return
        if m.command==DroneCommand.LAUNCH and self.state==DroneState.STORED: self.state=DroneState.LAUNCHING; self.hold_position=False
        elif m.command==DroneCommand.RETURN_HOME and self.state not in (DroneState.STORED,DroneState.DOCKED): self.state=DroneState.RETURNING; self.hold_position=False
        elif m.command==DroneCommand.HOLD_POSITION and self.state not in (DroneState.STORED,DroneState.DOCKED): self.state=DroneState.PAUSED; self.hold_position=True
        elif m.command==DroneCommand.GO_TO_STANDOFF and self.target: self.state=DroneState.STANDOFF; self.hold_position=False
        elif m.command==DroneCommand.RESUME and self.state==DroneState.PAUSED: self.state=DroneState.SEARCHING if self.target is None else DroneState.STANDOFF; self.hold_position=False
    def target_cb(self,m):
        if m.assigned_drone_id==self.id and m.target_id and self.state==DroneState.SEARCHING: self.target=m; self.state=DroneState.TARGET_DETECTED; self.alerted_target=None
    def decision_cb(self,m):
        if m.assigned_drone_id!=self.id or m.target_id!=(self.target.target_id if self.target else ''): return
        if self.state!=DroneState.AWAITING_OPERATOR: return

This is intentionally a lightweight dummy-target detector: it looks for a saturated

camera/OpenCV plumbing without pretending YOLO is already integrated.

class OpenCVDetector(Node):
    def __init__(self):
        super().__init__('opencv_detector')
        self.declare_parameter('drone_id','uav01')
        self.declare_parameter('target_class','dummy_animal')
        self.declare_parameter('min_area',250.0)
        self.declare_parameter('camera_height_m',10.0)
        self.declare_parameter('hfov_deg',78.0)
        self.did=self.get_parameter('drone_id').value
        self.cls=self.get_parameter('target_class').value

        self.pub=self.create_publisher(Detection,f'/drones/{self.did}/detections',10)
        self.sub=self.create_subscription(Image,f'/drones/{self.did}/camera/image_raw',self.image_cb,10)
        self.get_logger().info(f'OpenCV camera detector ready for {self.did}')
    def image_cb(self,msg):
        try: frame=self.bridge.imgmsg_to_cv2(msg,desired_encoding='bgr8')
        except Exception as exc:
            self.get_logger().warning(f'cv_bridge: {exc}'); return
        hsv=cv2.cvtColor(frame,cv2.COLOR_BGR2HSV)
        mask=cv2.inRange(hsv,(0,80,80),(35,255,255))
        contours,_=cv2.findContours(mask,cv2.RETR_EXTERNAL,cv2.CHAIN_APPROX_SIMPLE)
        if not contours:return
        c=max(contours,key=cv2.contourArea); area=cv2.contourArea(c)
        if area<float(self.get_parameter('min_area').value):return
        x,y,w,h=cv2.boundingRect(c); cx=x+w/2.0
        fov=math.radians(float(self.get_parameter('hfov_deg').value)); bearing=((cx/frame.shape[1])-0.5)*fov
        d=Detection(); d.header=msg.header; d.drone_id=self.did; d.detection_id=f'{self.did}_cv_{self.seq:06d}'; self.seq+=1
        d.target_class=self.cls; d.confidence=min(0.99,0.5+area/(frame.shape[0]*frame.shape[1]))
        # Camera-frame bearing is preserved as a simple local/world demo convention.
        d.position_world=Point(x=float(self.get_parameter('camera_height_m').value)*math.tan(bearing),y=0.0,z=0.0)
        d.covariance_xx=4.0; d.covariance_yy=4.0; d.distance_from_drone=float(self.get_parameter('camera_height_m').value)
        self.pub.publish(d)

class UGVGazeboAdapter(Node):

        self.declare_parameter('linear_speed',1.2); self.declare_parameter('yaw_gain',1.8)

import math
import rclpy
from rclpy.node import Node
from wildlife_interfaces.msg import Target, DroneState
class Coordinator(Node):
    def __init__(self):
        super().__init__('swarm_coordinator'); self.declare_parameter('assignment_period',1.0); self.declare_parameter('max_assignment_distance',50.0); self.declare_parameter('distance_weight',1.0); self.declare_parameter('target_confidence_weight',0.0)
        self.drones={}; self.assigned=set(); self.pub=self.create_publisher(Target,'/targets/assigned',20); self.create_subscription(Target,'/targets/unassigned',self.target_cb,20); self.create_subscription(DroneState,'/drones/state',self.drone_cb,50); self.create_timer(float(self.get_parameter('assignment_period').value),self.report)
    def drone_cb(self,m):
        self.drones[m.drone_id]=m
        if m.state in (DroneState.RETURNING,DroneState.DOCKING,DroneState.DOCKED,DroneState.PAUSED): self.assigned.discard(m.drone_id)
    def target_cb(self,t):
        if t.status!=Target.UNASSIGNED or t.assigned_drone_id: return
        cands=[d for d in self.drones.values() if d.state==DroneState.SEARCHING and d.drone_id not in self.assigned]
        if not cands: return
        dw=float(self.get_parameter('distance_weight').value); cw=float(self.get_parameter('target_confidence_weight').value); maxd=float(self.get_parameter('max_assignment_distance').value)
        def cost(d):
            dist=math.hypot(d.pose.pose.position.x-t.pose.pose.position.x,d.pose.pose.position.y-t.pose.pose.position.y); return dw*dist+cw*(1.-t.confidence)
        best=min(cands,key=cost); dist=math.hypot(best.pose.pose.position.x-t.pose.pose.position.x,best.pose.pose.position.y-t.pose.pose.position.y)
        if dist>maxd: return
        t.assigned_drone_id=best.drone_id; t.status=Target.ASSIGNED; self.assigned.add(best.drone_id); self.pub.publish(t); self.get_logger().info(f'Assigned {t.target_id} -> {best.drone_id} cost={cost(best):.2f}')
    def report(self): self.get_logger().debug(f'Coordinator: {sum(d.state==DroneState.SEARCHING for d in self.drones.values())} searching | {len(self.assigned)} assigned')
def main(args=None):
    rclpy.init(args=args); n=Coordinator(); rclpy.spin(n); n.destroy_node(); rclpy.shutdown()
