## Visdrone detector node · PY

C#!/usr/bin/env python3\
"""\
ROS 2 node: run a trained Ultralytics YOLO model (e.g. VisDrone best.pt) on a camera topic.\
\
Subscribes : sensor_msgs/Image                 (param: image_topic)\
Publishes  : vision_msgs/Detection2DArray      \~/detections\
&#x20;            sensor_msgs/Image (annotated)     \~/image_annotated   (only if someone subscribes)\
\
Run (after sourcing ROS 2):\
&#x20; python3 visdrone_detector_node.py --ros-args \\\
&#x20;     -p model_path:=/home/you/runs/visdrone_s/weights/best.pt \\\
&#x20;     -p image_topic:=/camera/image_raw \\\
&#x20;     -p imgsz:=1280 -p device:=0\
"""\
import rclpy\
from rclpy.node import Node\
from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy\
\
from sensor_msgs.msg import Image\
from vision_msgs.msg import Detection2DArray, Detection2D, ObjectHypothesisWithPose\
from cv_bridge import CvBridge\
from ultralytics import YOLO\
\
\
class VisDroneDetector(Node):\
&#x20;   def \_\_init\_\_(self):\
&#x20;       super().\_\_init\_\_("visdrone_detector")\
\
&#x20;       self.declare_parameter("model_path", "best.pt")\
&#x20;       self.declare_parameter("image_topic", "/camera/image_raw")\
&#x20;       self.declare_parameter("imgsz", 640)       # use the same size you trained at\
&#x20;       self.declare_parameter("conf", 0.25)\
&#x20;       self.declare_parameter("iou", 0.7)\
&#x20;       self.declare_parameter("device", "0")      # "0" = first GPU, "cpu" = CPU\
\
&#x20;       p = self.get_parameter\
&#x20;       self.imgsz = p("imgsz").value\
&#x20;       self.conf = p("conf").value\
&#x20;       self.iou = p("iou").value\
&#x20;       self.device = p("device").value\
\
&#x20;       self.get_logger().info(f"Loading model: {p('model_path').value}")\
&#x20;       self.model = YOLO(p("model_path").value)\
&#x20;       self.bridge = CvBridge()\
\
&#x20;       \# Depth-1 best-effort queue: if inference is slower than the camera,\
&#x20;       \# old frames are dropped instead of piling up (important on a drone).\
&#x20;       qos = QoSProfile(\
&#x20;           reliability=ReliabilityPolicy.BEST_EFFORT,\
&#x20;           history=HistoryPolicy.KEEP_LAST,\
&#x20;           depth=1,\
&#x20;       )\
&#x20;       self.sub = self.create_subscription(Image, p("image_topic").value, self.on_image, qos)\
&#x20;       self.det_pub = self.create_publisher(Detection2DArray, "\~/detections", 10)\
&#x20;       self.img_pub = self.create_publisher(Image, "\~/image_annotated", 1)\
\
&#x20;       self.get_logger().info("Detector ready.")\
\
&#x20;   def on_image(self, msg: Image):\
&#x20;       frame = self.bridge.imgmsg_to_cv2(msg, desired_encoding="bgr8")\
\
&#x20;       result = self.model.predict(\
&#x20;           frame,\
&#x20;           imgsz=self.imgsz,\
&#x20;           conf=self.conf,\
&#x20;           iou=self.iou,\
&#x20;           device=self.device,\
&#x20;           verbose=False,\
&#x20;       )[0]\
\
&#x20;       out = Detection2DArray()\
&#x20;       out.header = msg.header  # keep the camera timestamp/frame for downstream TF / tracking\
\
&#x20;       for xywh, score, cls in zip(\
&#x20;           result.boxes.xywh.cpu().tolist(),\
&#x20;           result.boxes.conf.cpu().tolist(),\
&#x20;           result.boxes.cls.cpu().tolist(),\
&#x20;       ):\
&#x20;           det = Detection2D()\
&#x20;           det.header = msg.header\
&#x20;           det.bbox.center.position.x = float(xywh[0])\
&#x20;           det.bbox.center.position.y = float(xywh[1])\
&#x20;           det.bbox.size_x = float(xywh[2])\
&#x20;           det.bbox.size_y = float(xywh[3])\
\
&#x20;           hyp = ObjectHypothesisWithPose()\
&#x20;           hyp.hypothesis.class_id = result.names[int(cls)]\
&#x20;           hyp.hypothesis.score = float(score)\
&#x20;           det.results.append(hyp)\
&#x20;           out.detections.append(det)\
\
&#x20;       self.det_pub.publish(out)\
\
&#x20;       \# Drawing boxes costs time, so only do it when something is listening (e.g. rqt / RViz).\
&#x20;       if self.img_pub.get_subscription_count() > 0:\
&#x20;           annotated = self.bridge.cv2_to_imgmsg(result.plot(), encoding="bgr8")\
&#x20;           annotated.header = msg.header\
&#x20;           self.img_pub.publish(annotated)\
\

# 10. What the additional settings mean

### `amp=True`

AMP means **Automatic Mixed Precision**.

It allows the GPU to perform many calculations using lower-precision numbers.

That normally:

- reduces VRAM consumption
- accelerates training
- retains suitable training accuracy

We want that on your RTX 4050.

---

### `patience=25`

Training watches validation performance.

If it doesn't improve for 25 consecutive epochs, Ultralytics can stop early rather than wasting computation.

So although we request:

```text
epochs=100
```

training could potentially stop earlier if performance has clearly stopped improving.

---

### `save_period=10`

YOLO will periodically save checkpoints.

For example:

```text
epoch10.pt
epoch20.pt
epoch30.pt
...
```

That gives you extra protection during training.

Ultralytics supports periodic checkpoint saving through `save_period`. :chatgpt-content-reference{index="7"}

# Phase L — Understanding the important metrics

After training you'll encounter metrics such as:

```text
Precision
Recall
mAP50
mAP50-95
```

Here's the beginner interpretation.

### Precision

Of all the objects the model claimed it detected:

> How many were actually correct?

High precision = fewer false alarms.

---

### Recall

Of all the real objects in the image:

> How many did the model successfully find?

High recall = fewer missed objects.

---

### mAP50

Mean Average Precision at an Intersection-over-Union threshold of 0.50.

Simplified:

> How well does the detector identify and locate objects when using a fairly forgiving bounding-box overlap requirement?

---

### mAP50-95

This evaluates performance using multiple increasingly strict bounding-box overlap requirements.

This is generally the more demanding overall detection metric.

When we compare two versions of your model later, **don't judge only by training loss**.

We'll look at:

```text
mAP50-95
mAP50
precision
recall
per-class performance
inference speed
```
