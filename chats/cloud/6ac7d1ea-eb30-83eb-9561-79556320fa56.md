This is the one I would build if this is for a university project.

Visually, your motors and 1045 propellers look like the sort of combination normally used on this class of quadcopter. **But check the motor label/KV rating before buying or issuing batteries and ESCs.** If you can photograph one motor outside the bag so I can see its model/KV specification, I can calculate the appropriate battery, ESC and approximate thrust.

The architecture would basically be:

**LiPo → power distribution → 4 ESCs → 4 motors**

while

**Pixhawk → ESC control signals**

and then:

**GPS/Compass → Pixhawk**  
**RC Receiver → Pixhawk**  
**Telemetry Radio → Pixhawk ↔ Laptop**  
**Optional companion computer → Pixhawk**

This can give you manual flight, stabilized flight, altitude hold, position hold, waypoint navigation, autonomous takeoff/landing, geofencing and later computer-vision control.

### 2. Crazyflie 2.1+ research drone

Those boxes in the final picture are **Crazyflie 2.1+** platforms. These are excellent if the project is more about:

- control algorithms,
- swarm robotics,
- indoor localization,
- autonomous navigation,
- ROS/ROS 2,
- Python programming,
- reinforcement learning,
- multi-agent systems,
- trajectory planning.

They are much smaller than the Pixhawk drone, though, and have very limited payload.

For an AI vision project where you eventually want to mount a substantial camera or computer, I would **not** choose Crazyflie as your main vehicle. For control/software research, though, they're extremely useful.
