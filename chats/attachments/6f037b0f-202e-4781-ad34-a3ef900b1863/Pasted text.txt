4. PROJECT PURPOSE
==================================================

This remains an academic, NON-CONTACT wildlife monitoring simulation.

The intended complete mission flow remains:

UGV
 -> deployment request
 -> UAV activation
 -> PX4 arming/takeoff
 -> search
 -> wildlife/dummy-target observation
 -> Detection
 -> target tracking/fusion
 -> persistent Target identity
 -> UAV assignment
 -> physical standoff
 -> operator notification
 -> operator chooses RETURN or CONTINUE_HOLD
 -> UAV follows operator decision
 -> return / landing / docking-state handling
 -> mission completion

The system consists conceptually of:

- 1 UGV;
- up to 8 UAVs;
- UAVs logically associated with four tray slots;
- simulated wildlife/dummy targets;
- PX4 SITL vehicles;
- Gazebo;
- ROS 2;
- QGroundControl;
- human-in-the-loop mission authority.
