# Human mesh and terrain asset provenance

V0.5-B1 uses 44 static pinned assets: eight clothed person derivatives, four cars, four trucks, three buses, sixteen terrain materials and nine unlabelled outdoor structures. Fixed camera calibration and class IDs are unchanged. These are synthetic scenes with improved mesh silhouettes and photographic terrain, not real-world aerial photographs or demonstrated detector accuracy.

## Sources and licenses

- Human source: [MakeHuman hm08 base mesh](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj), pinned revision a8bc2d54ff0ac92e78ff71431b1023eda42bf482. The mesh explicitly states CC0; official LICENSE.md separates CC0 bundled assets from AGPL application code. No application code is imported. Original base OBJ and license texts are retained under assets/upstream/makehuman. Derivatives use the smooth clothed tights proxy, retained head/hands, static lowered arms, eight adult heights/proportion/pose/clothing/skin/hair variants. All share hm08. **No independent person-model holdout is claimed.**
- Cars/trucks: [Kenney Car Kit 3.1](https://kenney.nl/assets/car-kit), CC0. Original archive, selected/source OBJ/MTL palette and License.txt are retained. Sedans, hatchback and SUVs are class car; truck/flatbed/delivery bodies are truck. Mesh axes and sizes are normalized to plausible meters and exact minimum Z=0. Source colors are muted; wheels, cabin, glazing and lights are retained. Geometry remains stylized.
- Terrain: twelve distinct [Poly Haven](https://polyhaven.com/license) CC0 photo/PBR assets. Official API info/files snapshots, authors and original albedo/GL-normal/roughness maps are retained. The API is accessed with a unique local software User-Agent. Grass/dirt/road sources are combined into deterministic 80 m mosaics repeated over 240 m surfaces, with meter-scale texture detail, irregular terrain/road boundaries and worn ground markings. Scale where absent from upstream metadata is an explicit project approximation. Index-3 sources are withheld from train/val; mixed/road margins use the same split-eligible source set. These flat terrain surfaces do not model elevation relief.
- Buses/context: original project CC0 static mesh construction with beveled coach bodies, windows/pillars, wheels, mirrors/roof units, slatted crates, irregular tree crowns, concrete barriers, supported corrugated roofs and masonry shadow walls. These are simplified geometry, not independent scans or real vehicle manufacturers.

The authoritative JSON/CSV manifest records each local file checksum, dependency checksums, source URL/revision, author/license, scale, measured bounds, polygon counts, eligibility, heldout status and shared template family. Rendering models use relative resource paths resolved only beneath the tool directory. Projection uses extreme vertices of the convex hull of rendered geometry; this preserves exact full-mesh projected bounds while avoiding repeated projection of interior vertices.

## Split interpretation and known limits

Vehicle test uses withheld geometry variants and terrain test uses withheld photographic sources. Person test reuses the hm08 template with varied scenes/appearance; it does not establish generalization to unseen human model families. Static poses and finite asset diversity limit variation. Some aerial people occupy only a few pixels; ignored reasons remain in metadata. Cast shadows are directional and hard-edged, vegetation is approximate, and terrain is planar. The intended improvement reduces visible abstraction; it makes no photorealism or sim-to-real performance claim.

Every original primitive asset checksum is preserved in legacy_primitive_assets.json, with original models/textures left intact. Prior primitive datasets are retained as historical technical evidence and are not approved under the new fidelity criteria.


The retained 240 m ground patch and fixed 100 m camera clip expose environment background at corners of some 30/40 m, 30-degree views: 111/2,000 pilot frames (maximum 5.53% of pixels) and **643/10,000 full frames (6.43%; maximum 7.045% of pixels)**. An analytical ground-ray/patch/far-plane check explains the boundary; these difficult factor levels are retained. Targets use a conservative far-bounded footprint. The images retain this known artifact. See [full extent evidence](evidence/full_background_extent_review.json) and [dataset report](DATASET_REPORT.md).
